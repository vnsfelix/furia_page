# FURIA – Chamados

1. Back-end: `cd javascript && npm install && npm start` (porta 3000; use `PORT` e `CORS_ORIGIN` se precisar).
2. Front-end: abra `index.html` com o Live Server (porta 5501) ou outro servidor estático.

Fluxo: login → `inicial/` (funcionário) ou `admin/` (admin) → `problemas/` ou `Presencial/` → `enviados/` (ou `errado/` se falhar). `conta/` e `chamados/` ficam no menu do perfil.
